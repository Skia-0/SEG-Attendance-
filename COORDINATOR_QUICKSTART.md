# SEG Attendance — Coordinator Quick-Start Guide

## Getting Started

### 1. Install The App
- Receive the APK file from your administrator
- Open the file on your Android phone
- If prompted, allow "Install from unknown sources"
- Tap Install → Open

### 2. Create Your Account
- Open the app → tap "Create Account"
- Enter your full name
- Enter your SEG work email
- Create a password (8+ characters, must include a letter and number)
- Tap Next → Enter your hub name and location
- Check your email for a 6-digit verification code
- Enter the code → you're logged in!

### 3. Create A Cohort
- From the home screen, tap "+ New Cohort"
- Enter cohort name (e.g. "Poultry Management")
- Set start and end dates
- Set minimum attendance percentage (default 80%)
- Tap Create Cohort

### 4. Register Learners
- Open your cohort → tap "Learners"
- Tap "+ Add Learner"
- Enter learner's full name
- Scan their NFC card (hold card to back of phone)
- Enroll their fingerprint (learner places finger on sensor)
- Take a photo (optional)
- Tap Register → SEG ID is assigned automatically

### 5. Run A Session
- Open your cohort → tap "New Session"
- Enter session title (e.g. "Week 3 - Monday")
- Tap Start Session

### 6. Take Attendance
**Check-In:**
- Tap "Check-In" button (turns orange when open)
- NFC: Learner taps their card on back of your phone
- Fingerprint: Tap fingerprint button → select learner → verify
- Manual: Tap pencil button → select learner → enter reason
- Each learner's status updates in real-time

**Check-Out:**
- Tap "Check-Out" button
- Repeat the same process

**End Session:**
- Tap "End Session"
- If learners haven't checked out, enter a reason
- Optionally submit the session report to SEG central

### 7. View Reports
- Open cohort → tap "Summary" to see certification status
- Open cohort → tap "At-Risk" to see struggling learners
- Profile → "Submitted Reports" to see your report history

### 8. Submit Reports
**Session Report:** After ending a session, you can submit it immediately or later from session details.

**Cohort Final Report:** When the cohort ends, tap "Submit Final Report To SEG" on the cohort detail screen.

⚠️ Reports can only be submitted ONCE. Contact your admin if a correction is needed.

## Troubleshooting

**Can't log in?**
- Check your email and password
- After 5 wrong attempts, account locks for 30 minutes
- Use "Forgot password?" to reset via email

**App says "Server waking up"?**
- Wait 30 seconds and try again
- The server goes to sleep after inactivity

**Fingerprint not working?**
- Ensure at least one fingerprint is enrolled in phone Settings
- Phone must have a fingerprint sensor

**NFC card not detected?**
- Hold the card flat against the back of the phone
- Hold for 2-3 seconds
- Some phone cases block NFC — try without the case

**Can't start new session?**
- End the current active session first
- Only one session per cohort can be active

---

## Important Rules

1. Only ONE session can be active per cohort at a time
2. Sessions must be ended before submitting reports
3. Reports can only be submitted ONCE per session/cohort
4. Manual overrides require a reason (logged for audit)
5. NFC cards must be returned at cohort end
6. Keep learner consent forms on file at the hub
